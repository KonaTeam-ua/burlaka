# Отслеживание цен

`prices.json` — список товаров, за ценой которых следит ежедневная
автоматическая проверка (Routine в Claude Code). При каждом запуске Claude
открывает каждую ссылку, записывает текущую цену в `history`, обновляет
`last_price` / `lowest_price` / `last_checked` и присылает уведомление на
телефон, если цена стала ниже предыдущей.

Чтобы добавить товар — допишите в `items` объект с `name` и `url`
(остальные поля можно оставить `null` / `[]`), или просто попросите Claude.
