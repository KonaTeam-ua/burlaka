# burlaka — мини-приложение для управления проектами

Простое одностраничное приложение (без бэкенда и сборки) для управления
проектами и задачами в формате канбан-доски.

## Возможности

- создание, переименование и удаление проектов;
- создание, редактирование и удаление задач;
- три колонки статуса: «К выполнению», «В работе», «Готово»;
- перенос задач между колонками перетаскиванием (drag-and-drop);
- приоритет задачи (низкий / средний / высокий) и срок выполнения
  с подсветкой просроченных задач;
- прогресс по проекту (сколько задач выполнено из общего числа);
- все данные сохраняются в `localStorage` браузера — сервер не требуется.

## Запуск

Приложение не требует сборки и зависимостей. Достаточно открыть
`index.html` в браузере, либо поднять любой статический сервер, например:

```bash
python3 -m http.server 8000
```

и перейти на `http://localhost:8000`.

## Структура

- `index.html` — разметка страницы и диалоговые окна создания/редактирования;
- `style.css` — стили интерфейса;
- `app.js` — логика приложения (хранение состояния, рендер доски, обработчики событий).
